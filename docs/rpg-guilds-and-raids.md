## Пидор-Рояль: гильдии и рейды

Этот документ описывает гильдейную систему, гильдейские боссы и рейды, а также базовый UX работы с гильдиями в Telegram.

### 1. Гильдии (пидорские кланы)

#### 1.1. Сущность `guild`

Логическая структура таблицы `guild`:

- `id SERIAL`
- `name TEXT UNIQUE` — название гильдии (может содержать пидорский юмор).
- `tag TEXT UNIQUE` — короткий тег (латиницей, для быстрого упоминания).
- `leader_player_id INT REFERENCES rpg_player(id)` — лидер (главный пидор).
- `level INT DEFAULT 1` — уровень гильдии.
- `xp BIGINT DEFAULT 0` — опыт гильдии.
- `description TEXT` — описание.
- `created_at TIMESTAMPTZ`
- `updated_at TIMESTAMPTZ`

Опциональные поля:

- `emblem TEXT` — код эмодзи/стикера-эмблемы.
- `settings JSONB` — флаги (открытый набор, требования к вступлению и т.п.).

#### 1.2. Сущность `guild_member`

Таблица `guild_member`:

- `guild_id INT REFERENCES guild(id)`
- `player_id INT REFERENCES rpg_player(id)`
- `role TEXT` — `leader`, `officer`, `member`, `recruit`.
- `joined_at TIMESTAMPTZ`
- опционально: `contribution BIGINT` — вклад игрока в гильдию (урон по боссам, выполненные квесты).

Уникальный ключ `(guild_id, player_id)`.

#### 1.3. Роли и права

Роли и их права (минимальный набор):

- `leader` (главный пидор):
  - приглашает и кикает игроков;
  - повышает/понижает до `officer`;
  - запускает рейды и выбирает босса;
  - редактирует описание и настройки.
- `officer`:
  - приглашает игроков;
  - одобряет заявки;
  - может запускать рейд, если лидер дал права в настройках.
- `member`:
  - участвует в рейдах и активностях;
  - может приглашать по пригласительным ссылкам, если это разрешено.
- `recruit`:
  - свежепринятый участник; после некоторого вклада/времени автоматически или вручную повышается до `member`.

Ролевые названия в интерфейсе могут быть стилизованы («Главный пидор», «Старший пидор», «Пидор-стажёр» и т.п.), но в БД хранятся кодами.

### 2. Механики гильдий

#### 2.1. Создание гильдии

- Условия:
  - минимальный уровень персонажа;
  - достаточный запас золота/ресурса.
- Команда/кнопка:
  - через Дом гильдий в городе (`🏰 Дом гильдий` → `Создать гильдию`).
- Поток:
  1. Бот спрашивает название, тег, описание (через последовательность сообщений/кнопок).
  2. Проверяет уникальность `name` и `tag`.
  3. Списывает стоимость, создаёт запись в `guild`.
  4. Создаёт `guild_member` с ролью `leader`.

#### 2.2. Вступление в гильдию

- Поиск гильдий:
  - меню Дом гильдий → `Найти гильдию` (список топовых/открытых, поиск по имени/тегу).
- Вступление:
  - либо **заявка** (офицер/лидер одобряет);
  - либо **автовступление**, если гильдия открытая.
- Выход:
  - кнопка `Покинуть гильдию` в меню `Моя гильдия`.

#### 2.3. Уровень и опыт гильдии

- Гильдия получает XP за:
  - участие членов в рейдах;
  - убийство гильдейских и мировых боссов;
  - выполнение гильдейских квестов.
- Уровень гильдии:
  - даёт:
    - увеличение лимита членов;
    - пассивные бонусы (например, +XP, +шанс лута, +резисты).
  - хранится в полях `level` и `xp` в `guild`.

### 3. Гильдейские боссы и рейды

#### 3.1. Шаблоны боссов

Таблица `guild_boss_template`:

- `id SERIAL`
- `code TEXT UNIQUE`
- `name TEXT`
- `description TEXT`
- `recommended_level INT`
- `max_hp BIGINT`
- `attack_pattern JSONB` — логика атак (фазы, навыки).
- `loot_table_code TEXT` — код таблицы лута.

#### 3.2. Активный рейд гильдии

Таблица `guild_raid`:

- `id SERIAL`
- `guild_id INT REFERENCES guild(id)`
- `boss_id INT REFERENCES guild_boss_template(id)`
- `status TEXT` — `active`, `finished`, `failed`.
- `hp_left BIGINT` — оставшееся HP босса.
- `phase_state JSONB` — фаза босса, наложенные эффекты.
- `started_at TIMESTAMPTZ`
- `finished_at TIMESTAMPTZ NULL`

`guild` может иметь либо 0, либо 1 активный рейд за раз (ограничение бизнес-логики).

#### 3.3. Участие игроков в рейде

Таблица `guild_raid_participation`:

- `raid_id INT REFERENCES guild_raid(id)`
- `player_id INT REFERENCES rpg_player(id)`
- `damage_done BIGINT`
- `healing_done BIGINT`
- `hits INT`
- `deaths INT`

Уникальный ключ `(raid_id, player_id)`.

Данные используются для:

- расчёта наград;
- отображения таблицы вклада;
- ачивок (топовый ДПС, выживший, чаще всех умирал и т.п.).

#### 3.4. Механика рейда (асинхронный босс)

- Рейд запускается лидером/офицером через меню Дом гильдий:
  - выбор босса и подтверждение.
- Каждый участник может:
  - нажать `⚔ Войти в бой` → запускается PvE-бой против босса:
    - по сути, отдельный `rpg_battle` со ссылкой на `raid_id`;
    - наносимый урон суммируется в `guild_raid.hp_left`.
- Ограничения:
  - N попыток на игрока (в день/за рейд);
  - общий таймер рейда (например, 24–72 часа).
- Завершение:
  - если `hp_left <= 0` до истечения времени → `status = finished`;
  - иначе по таймеру → `failed`.

#### 3.5. Награды

- Общие принципы:
  - все участники, нанесящие урон выше некоторого порога, получают базовую награду;
  - топ-участники (по урону/вкладу) получают дополнительные/улучшенные награды.
- Награда состоит из:
  - XP и золота;
  - предметов из `loot_table_code`;
  - гильдийского опыта (`guild.xp`).

### 4. Гильдии на карте мира

- На глобальной карте:
  - есть **дом гильдий в столице** (здание в городе);
  - есть **гильдейские/рейдовые зоны** (`raid_zone`) — особые клетки для запуска рейдов:
    - одиночных (одна гильдия против босса);
    - общих (несколько гильдий, «мировой босc»).
- При входе в рейдовую зону:
  - игрок/гильдия видит меню:
    - `О боссе`, `⚔ Начать рейд`, `📊 Прогресс`, `⬅ Уйти`.

### 5. Телеграм-UX для гильдий

#### 5.1. Дом гильдий в городе

В локальной карте города есть здание `🏰 Дом гильдий`.

При входе:

- если игрок **не в гильдии**:
  - текст:
    - «Ты зашёл в Дом гильдий. Здесь обитают организованные пидоры.»
  - кнопки:
    - `Создать гильдию`
    - `Найти гильдию`
    - `Мои заявки`
    - `⬅ Назад в город`
- если игрок **в гильдии**:
  - текст:
    - краткая инфа по гильдии (название, уровень, количество участников, бонусы).
  - кнопки:
    - `Состав`
    - `Гильдейский босс`
    - `Настройки` (для лидера/офицеров)
    - `Выйти из гильдии`
    - `⬅ Назад в город`

#### 5.2. Меню гильдейского босса

Если у гильдии есть активный рейд:

- текст:
  - `Босс: <имя>`, `HP: X / Y`, фаза, таймер до конца.
- кнопки:
  - `⚔ Войти в бой`
  - `📊 Вклад участников`
  - `📜 О боссе`
  - `⬅ Назад`

Если активного рейда нет:

- список доступных боссов с кратким описанием;
- кнопки:
  - `Запустить рейд` рядом с каждым боссом (если достаточно прав/ресурсов).

### 6. Приоритеты реализации по этому документу

1. **MVP-уровень гильдий**:
   - таблицы `guild` и `guild_member`;
   - создание/вступление/выход через Дом гильдий;
   - отображение профиля гильдии и списка участников.
2. **Гильдейский босс (общая логика)**:
   - таблицы `guild_boss_template`, `guild_raid`, `guild_raid_participation`;
   - запуск рейда и фиксация вклада игроков.
3. **Интеграция с боёвкой**:
   - привязка PvE-боя к `raid_id`;
   - уменьшение `hp_left` по результату боя.
4. **Награды и гильдийский опыт**:
   - базовая логика распределения лута и XP;
   - повышение уровня гильдии.
