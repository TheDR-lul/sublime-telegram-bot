# Инструкция по запуску и тестированию бота

## Шаг 1: Создание бота в Telegram

1. Откройте Telegram (приложение или https://web.telegram.org)
2. Найдите @BotFather
3. Отправьте команду `/newbot`
4. Следуйте инструкциям:
   - Введите имя бота (например: "Sublime Test Bot")
   - Введите username бота (должен заканчиваться на `bot`, например: `sublime_test_bot`)
5. Скопируйте токен, который выдаст @BotFather (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Настройка базы данных

Убедитесь, что у вас запущен PostgreSQL. Если нет - установите или используйте удаленную БД.

Пример строки подключения:
```
postgresql://username:password@localhost:5432/sublime_bot
```

## Шаг 3: Настройка конфигурации

### Вариант 1: Интерактивная настройка (рекомендуется)

```bash
cargo run -- config init
```

Введите токен бота и DATABASE_URL когда попросит.

### Вариант 2: Через переменные окружения

Создайте файл `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=postgresql://user:password@localhost/dbname
RUST_LOG=sublime=info
```

### Вариант 3: Создать config.toml вручную

Создайте файл `config.toml` в корне проекта:

```toml
telegram_token = "ваш_токен_от_BotFather"
database_url = "postgresql://user:password@localhost/dbname"
```

## Шаг 4: Применение миграций

```bash
cargo run -- migrate
```

## Шаг 5: Регистрация команд бота (опционально)

```bash
cargo run -- commands set
```

## Шаг 6: Запуск бота

```bash
cargo run
```

или

```bash
cargo run -- run
```

## Шаг 7: Тестирование

1. Найдите вашего бота в Telegram по username
2. Начните чат с ботом (нажмите Start)
3. Протестируйте команды:
   - `/about` - информация о репозитории
   - `/hello` - приветствие
   - `/pidorules` - правила игры
   - `/pidoreg` - регистрация в игру
   - `/pidor` - запуск игры (нужно минимум 2 игрока)
   - `/meme` - случайный мем
   - `/get test` - получить значение по ключу
   - `/set test hello` - установить значение
   - `/list` - список всех ключей

## Устранение проблем

### Ошибка подключения к БД
- Убедитесь, что PostgreSQL запущен
- Проверьте правильность DATABASE_URL
- Убедитесь, что база данных существует

### Ошибка токена
- Проверьте правильность токена от @BotFather
- Убедитесь, что токен не содержит лишних пробелов

### Бот не отвечает
- Проверьте логи (должны быть видны сообщения с `RUST_LOG=sublime=info`)
- Убедитесь, что бот запущен и не завершился с ошибкой
