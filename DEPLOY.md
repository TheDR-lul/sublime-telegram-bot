# Deployment Instructions

## Обновление бота на сервере (через Docker)

Для обновления бота на сервере из локальной среды Windows используйте скрипт `update.ps1`. Он соберет бинарь (через кросс-компиляцию или в докере), отправит его на сервер и перезапустит контейнеры.

```powershell
./update.ps1
```

## Работа с базой данных (SQL)

### Бекапы
Локальные бекапы сохраняются в папку `backups/`. Скрипт автоматической очистки удаляет файлы старше 7 дней.

Чтобы сделать бекап вручную на сервере:
```bash
docker exec -t sublime-db-1 pg_dumpall -c -U postgres > backup_$(date +%Y%m%d_%H%M%S).sql
```

### Миграции
Миграции применяются автоматически при запуске бота через `sqlx::migrate!`. При добавлении нового `.sql` файла в `migrations/` он будет выполнен при следующем рестарте.

## Полезные команды на сервере

- Просмотр логов: `docker compose logs -f bot`
- Перезагрузка: `docker compose restart bot`
- Статус контейнеров: `docker compose ps`
